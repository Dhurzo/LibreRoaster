<task type="auto">
  <name>Task 1: Capture dead code signals</name>
  <files>scripts/dead-code-inventory.sh</files>
  <action>
    Create a hardened shell script that:
    - Enforces `set -euo pipefail` and writes output under `quality/dead-code/inventory/<timestamp>-dead-code.json`.
    - Runs `cargo clippy --locked --all-targets --all-features --message-format=json` and filters the JSON for lint codes that include `dead_code`/`dead_code_in_same_module` (using `jq` or `rg`).
    - Records the git HEAD, toolchain, and timestamp alongside each candidate so reviewers know when/how the signal was captured.
    - Emits a human-readable summary (module, item, line, risk hints) plus a JSON payload for automation.
    - Leaves the directory structure in place so downstream scripts can read the latest inventory without recreating it.
  </action>
  <verify>
    Run `scripts/dead-code-inventory.sh` and confirm it exits 0 while writing `quality/dead-code/inventory/dead-code-inventory.json` that contains at least one `dead_code` entry and `git_rev` metadata. Use `rg -n "dead_code" quality/dead-code/inventory/dead-code-inventory.json` to confirm.
  </verify>
  <done>
    The inventory script exists, runs cleanly, and drops structured `dead_code` candidates plus metadata into `quality/dead-code/inventory` so reviewers can inspect or automate decisions.
  </done>
</task>
