    3. Run `cargo fmt -- --check` to verify code formatting.
    4. Run `cargo clippy --workspace --all-features -- -D warnings` to enforce linting with warnings as errors.
    5. Run `cargo test --workspace --all-features` to execute all tests.
    6. Ensure the script is executable (`chmod +x`).

    The script's content should be as follows:

    ```bash
    set -euxo pipefail

    echo "Running cargo fmt -- --check..."
    cargo fmt -- --check

    echo "Running cargo clippy --workspace --all-features -- -D warnings..."
    cargo clippy --workspace --all-features -- -D warnings

    echo "Running cargo test --workspace --all-features..."
    cargo test --workspace --all-features

    echo "All quality checks passed."
    ```
  </action>

  </done>
