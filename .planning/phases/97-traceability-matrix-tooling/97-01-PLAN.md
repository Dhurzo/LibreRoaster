<objective>
Add traceability instrumentation so every Artisan command can be observed from ingest through actuator/telemetry/guard outcomes.

Purpose: Regression triage needs a matrix (command → queue → actuator → telemetry → guard) but the current STAGE/STATUS streams are disconnected. A dedicated `TRACE` stream with TraceIds plus queue/control instrumentation delivers the required correlation without changing the runtime architecture.

Output: `src/logging/traceability.rs` with TraceId helpers, queue/hardware tasks that wrap commands and emit enqueue/dequeue events, and an updated control loop that tags actuator/telemetry/guard outputs with the same TraceId.
</objective>
