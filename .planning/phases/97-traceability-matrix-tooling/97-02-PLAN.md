  <name>Write traceability matrix parser</name>
  <files>scripts/traceability_matrix.py</files>
  <action>
    Build a Python script that transforms the firmware `TRACE` log into the demanded matrix:

    1. Accept a log path argument, read lines, and ignore non-`TRACE` entries.
    2. Parse entries of the form `TRACE,<trace_id>,<step>,key=value,...` into a dict keyed by `trace_id` and record the latest command name, queue depth, SSR/fan outputs, telemetry numbers (ET/BT/PV/MV), and guard/watchdog flags.
    3. After consuming the file, print a table (plain text or CSV) listing each `TraceId`, command, queue depth, actuator outputs, telemetry snapshot, and guard/watchdog summary so regression triage can spot where the flow broke.
    4. Exit with zero even when the log contains non-TRACE chatter (e.g., `STATUS` lines). Document expected columns in the script header docstring or inline help.
  </action>
