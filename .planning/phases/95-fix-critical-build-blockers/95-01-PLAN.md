# Plan 95-01: Fix Critical main.rs Compilation Issues

**Phase:** 95-Fix Critical Build Blockers
**Priority:** CRITICAL (blocks all binary production)
**Dependencies:** None
**Estimated Time:** 1-2 hours

## Goal

Resolve compilation errors in main.rs that prevent building flashable .bin binary with --features embedded flag.

## Context

From Phase 93 verification:
- Build documentation is correct (--features embedded flag added)
- Binary target is enabled via required-features = ["embedded"]
- BUT: Pre-existing code bugs in main.rs prevent compilation
- Missing generic arguments, missing attributes, undefined variables

## Specific Issues to Fix

1. **Missing generic arguments on SsrControlSimple type**
   - Type instantiation incomplete

2. **Missing #[esp_rtos::main] attribute on entry function**
   - Entry function lacks required RTOS attribute

3. **Multiple undefined variable references**
   - Variables used but not declared/in scope

## Success Criteria

1. ✅ `cargo build --features embedded` completes successfully
2. ✅ Flashable .bin binary produced in target/riscv32imc-unknown-none-elf/release/
3. ✅ No compilation errors or warnings
4. ✅ Binary can be flashed (verification with esptool)

## Implementation Steps

1. **Analyze current main.rs**
   - Identify all compilation errors
   - Document each issue with line numbers and context

2. **Fix generic arguments**
   - Add correct type parameters to SsrControlSimple
   - Verify type signatures match usage

3. **Add entry attribute**
   - Add #[esp_rtos::main] to entry function
   - Verify function signature matches attribute requirements

4. **Resolve undefined variables**
   - Declare missing variables
   - Fix variable scope issues
   - Ensure all references are valid

5. **Verify build**
   - Run `cargo build --features embedded --release`
   - Confirm .bin binary produced
   - Verify no errors or warnings

## Testing

1. Build verification:
   ```bash

   ```

2. Binary verification:
