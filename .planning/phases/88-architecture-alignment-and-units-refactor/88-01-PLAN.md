  <action>
Wire UNITS command through ManualCommandPolicy by modifying process_command:

1. In the match on ArtisanCommand (around line 675), modify the Units case to convert to RoasterCommand and use forward_artisan_manual_command:

```rust
crate::config::ArtisanCommand::Units(is_fahrenheit) => {
    // Convert to RoasterCommand and forward through policy
    let cmd = crate::config::RoasterCommand::SetUnits(is_fahrenheit);
    return self.forward_artisan_manual_command(cmd, current_time);
}
```

2. Remove the direct Units handling that directly sets temp_settings (the old code at lines 675-682).

The key insight: forward_artisan_manual_command calls process_command recursively, which will then:
- Check can_handle (will match SetUnits)
- Call evaluate (will set temp_settings via ManualPolicyOutcome)
- Return success

This is the same pattern used for other manual commands like SetHeater, SetFan, IncreaseHeater, DecreaseHeater.
