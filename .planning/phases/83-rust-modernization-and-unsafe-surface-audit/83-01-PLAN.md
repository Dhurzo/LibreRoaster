<task type="auto">
  <name>Create modernization automation script</name>
  <files>scripts/run-modernization.sh</files>
  <action>
1. Create `scripts/run-modernization.sh` with `set -euo pipefail`, derive `RUN_ID` using `date -u +%Y%m%dT%H%M%SZ` plus `$RANDOM`, and ensure `mkdir -p "logs/modernization/$RUN_ID"` before running commands.
2. Run `cargo fmt`, `cargo fix --allow-dirty --allow-staged`, and `cargo clippy --all-targets --all-features -- -D warnings -D clippy::pedantic` sequentially, piping each step’s stdout/stderr to `logs/modernization/$RUN_ID/step-XX-<name>.log` while also teeing to the console.
3. After the commands finish, append an auto-report fragment (`unsafe_register_changes`, `log_path`, `run_id`) to `logs/modernization/$RUN_ID/summary.txt` so auditors can quickly identify touched unsafe surfaces for that run.
4. Allow the script to accept an optional `SKIP_REASON` input (flag or env var) and, when provided, append `skip_reason = "<reason>"` to the summary earlier in the file to explain why behavior-critical modules were skipped.
  </action>
  <verify>
1. `bash -n scripts/run-modernization.sh` succeeds.
2. `rg -n "cargo fmt" scripts/run-modernization.sh` and `rg -n "cargo fix" scripts/run-modernization.sh` confirm the expected commands are present.
3. `rg -n "mkdir -p \"logs/modernization" scripts/run-modernization.sh` confirms the log directory is created before the commands run.
4. `rg -n "skip_reason" scripts/run-modernization.sh` confirms the script records provided skip reasons in the summary.
  </verify>
  <done>
Script runs `cargo fmt`, `cargo fix`, and pedantic `cargo clippy` inside a timestamped log directory and writes a per-run summary that references the unsafe register delta.
