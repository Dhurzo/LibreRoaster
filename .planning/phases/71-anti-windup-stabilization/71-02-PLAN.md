  <action>
1. Track the previous PV sample and timestamp inside `RoasterControl` and compute `dt` (use `current_time.duration_since(last_time)`). Bail out if `dt == 0` or no previous sample exists so derivative stays zero.
2. Build a lightweight filter (alpha ~0.3) that mixes the instantaneous PV delta (`(current_pv - prev_pv) / dt_secs`) with the last filtered derivative so telemetry ignores sensor noise.
3. Store the filtered value in `self.status.derivative_rate` and set `self.status.derivative_available = true` only when `dt` and the computed rate are finite; otherwise keep it `false` and zero the rate.
4. Keep the `last_pv_sample`/`last_pv_sample_time` pair in sync so the next tick builds on the filtered result.
  </action>
