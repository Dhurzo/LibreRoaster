# The key insight
- Max31856 implements BOTH Thermometer and AsyncThermometer traits
- When stored as Box<dyn Thermometer>, only sync methods are accessible
- When stored as concrete Max31856 type, both sync and async methods accessible
- This is the solution to the dyn + async limitation
