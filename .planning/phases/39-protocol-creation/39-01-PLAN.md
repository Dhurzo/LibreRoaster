  <action>
    Add detailed READ and UNITS command documentation to PROTOCOL.md:

    **READ - Telemetry Response**
    - Syntax: READ
    - Description: Request current temperature and status telemetry
    - Response Format: 4-value CSV (ET,BT,HEATER,FAN)
      - ET: Exhaust Temperature (°C, one decimal)
      - BT: Bean Temperature (°C, one decimal)
      - HEATER: Heater PWM percentage (0-100)
      - FAN: Fan PWM percentage (0-100)
    - Example Command: READ
    - Example Response: 185.3,201.4,45,80
    - Note: 4-value format (corrected from 7-value legacy spec)
    - Unused channels: ET2 and BT2 return -1 (placeholder behavior)
    - Precision: One decimal place (e.g., 75.0)

    **UNITS - Temperature Scale Preference**
    - Syntax: UNITS\<value\>
    - Description: Set temperature display preference (C or F)
    - Parameters table: Value | Type | Description
    - Valid values: C (Celsius), F (Fahrenheit)
    - Example: UNITSF
    - Response: OK or ERR
    - Important Implementation Note: UNITS is parse-only
      - Preference is stored but NO temperature conversion occurs
      - All internal temperatures remain in Celsius regardless of setting
      - Refer to ARCHITECTURE.md for implementation details
    - Behavior note: Parse-only, no conversion applied
