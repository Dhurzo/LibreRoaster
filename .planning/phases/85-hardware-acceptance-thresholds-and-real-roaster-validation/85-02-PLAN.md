  <name>Task 2: Develop Threshold Analysis Logic</name>
  <files>tests/hardware/analysis.py</files>
  <action>
    1. Create `tests/hardware/analysis.py` using `pandas`.
    2. Load `thresholds.json`.
    3. Implement checks:
       - `max_command_latency_ms`: Find the maximum value in the CSV. Since firmware reports in µs, include division by 1000.0.
       - `avg_command_latency_ms`: Calculate the mean (convert µs to ms).
       - `max_watchdog_consecutive_fails`: Check if any row has value > 0.
       - `max_ledc_guard_timeouts`: Check the last recorded value against the threshold.
    4. Provide a structured result (dict) with pass/fail for each metric.
  </action>
  <verify>`python3 analysis.py --csv some_sample.csv` correctly reports pass/fail based on mock data.</verify>
  <done>Validation analysis logic is complete and tested against mock data.</done>
</task>
