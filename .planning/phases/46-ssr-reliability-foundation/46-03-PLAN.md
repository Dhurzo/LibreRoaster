<task type="auto">
  <name>Task 1: Detect LEDC drift and retry when tolerance is exceeded</name>
  <files>src/hardware/ssr.rs</files>
  <action>
After every `pwm_channel.set_duty`, read back the applied duty (`ChannelIFace::get_duty` or the raw LEDC register) and compare it to the commanded `current_duty`. If the absolute delta exceeds `SSR_DUTY_TOLERANCE_TICKS`, log a warning, increment a retry counter (even if limited to a single retry), and reapply the duty once before returning an error.

Expose a helper `fn last_lead_delta_ticks(&self) -> i16` (or similar) that returns the signed tick difference so telemetry can show how far hardware drifted.
  </action>
  <verify>cargo test --test ssr_monitor</verify>
  <done>The LEDC monitor reruns the command when drift exceeds ±2 ticks and exposes the signed delta for RoasterControl to consume.</done>
</task>
