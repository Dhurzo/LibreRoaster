The uart_reader_task import at line 10 is only used in a #[cfg(target_arch = "riscv32")] code block (line 137).
When building for x86_64 (the host target), the import is unused because the entire function is cfg-gated.

Current (line 10):
```rust
use crate::hardware::uart::{send_response, uart_reader_task, COMMAND_PIPE_SIZE};
```

Fix: Gate the import with the same cfg attribute as the usage. Split into two cfg-gated imports:

```rust
#[cfg(target_arch = "riscv32")]
use crate::hardware::uart::{send_response, uart_reader_task, COMMAND_PIPE_SIZE};
#[cfg(not(target_arch = "riscv32"))]
use crate::hardware::uart::{send_response, COMMAND_PIPE_SIZE};
```

This ensures the import only exists when the code that uses it is compiled.
