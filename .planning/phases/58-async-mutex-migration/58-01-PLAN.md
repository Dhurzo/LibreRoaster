  <files>src/application/service_container.rs</files>
  <action>
Add new async method that uses lock pattern:

1. After with_roaster_mut() (around line 98), add:
```rust
/// Async access to RoasterControl - use this in async task contexts
pub async fn with_roaster_async<R, F>(f: F) -> Result<R, ContainerError>
where
    F: FnOnce(&mut RoasterControl) -> R,
{
    let mut guard = self.roaster.lock().await;
    Ok(f(&mut guard))
}
```

2. Also add a static async version for convenience:
```rust
/// Static async access to RoasterControl
pub async fn with_roaster_async<R, F>(f: F) -> Result<R, ContainerError>
where
    F: FnOnce(&mut RoasterControl) -> R,
{
    let mut guard = Self::get_instance().roaster.lock().await;
    Ok(f(&mut guard))
}
```
