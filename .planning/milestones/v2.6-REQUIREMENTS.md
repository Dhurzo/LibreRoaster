# Requirements: LibreRoaster

**Defined:** 2026-02-17
**Core Value:** Artisan can read temperatures and control heater/fan during a roast session via serial connection.

## v1 Requirements

### SSR Control

- [x] **SSR-01**: Artisan SSR commands map 0-100 to LEDC duty 0-255 using saturating conversion so 100% always writes 255 and 0% writes 0.
- [x] **SSR-02**: The SSR scheduler enforces the datasheet minimum cycle time (≥1 second) and queues or rejects commands issued while the previous cycle is still active.
- [x] **SSR-03**: Each SSR update validates the LEDC channel's applied duty (within ±2 ticks of the command) and retries or logs a fault when the hardware diverges.

### Fan Control

- [x] **FAN-01**: FanController writes LEDC duty via `set_duty`/`update_duty` so the actual PWM channel reflects every Artisan fan command instead of only updating an in-memory struct.
- [x] **FAN-02**: Fan and SSR LEDC writes are serialized (including fades when fans spin up/down) to avoid timer collisions and audible jumps.

### Async Transport

- [x] **IO-01**: UART transport uses embassy async UART traits with buffered event queues so reads/writes run as futures and never block the executor.
- [x] **IO-02**: USB CDC transport (embassy-usb + Synopsys OTG) exposes DMA-aware CDC ACM futures with back-pressure handling so the formatter yields when the endpoint is busy.
- [x] **IO-03**: The command multiplexer/formatter yields whenever a transport reports congestion and resumes automatically once the queue drains, preventing executor stalls.

### Testing & Monitoring

- [x] **TEST-01**: Host or hardware tests verify SSR updates reach the LEDC channel within ±2 ticks and enforce the cycle-time guardrails. *(Hardware verification still pending per `.planning/phases/46-ssr-reliability-foundation/46-VERIFICATION.md`.)*
- [x] **TEST-02**: Integration tests flood UART and USB transports while SSR/fan loops operate to prove the executor stays responsive and no commands are dropped.

## v2 Requirements

### Observability

- **OBS-01**: Telemetry channel showing SSR/fan duty versus Artisan commands (defer until hardware reliability is proven).
- **OBS-02**: Dynamic PWM frequency reconfiguration across board variants (future milestone once LEDC stability exists).
