## Architecture

### Before (v2.3)
```
USB Serial: Mixed Artisan + Debug logs
UART0: Unused or mixed
```

### After (v2.4)
```
UART0: All logging (info!, debug!, warn!, error!)
USB Serial: Artisan protocol only
```

### Logging Flow
```
info!(), debug!(), warn!(), error!
    ↓
log crate
    ↓
esp_println::logger::init_logger_from_env()
    ↓
esp_println::println!()
    ↓
UART0 peripheral (GPIO20 TX)
```

### USB Serial Flow
```
ArtisanFormatter::format()
    ↓
usb.write_bytes()
    ↓
USB Serial (UsbSerialJtag)
    ↓
Artisan commands/responses ONLY
```

---

## Key Decisions

| Decision | Rationale |
|----------|-----------|
| Use esp_println for UART0 output | Simpler than defmt-rtt, direct UART0 access |
| Keep ArtisanFormatter protocol-only | No interference with Artisan communication |
| Remove USB CDC debug output | Debug logs were interfering with protocol |
| Channel prefixes [USB], [UART], [SYSTEM] | Helps debugging which channel has issues |
