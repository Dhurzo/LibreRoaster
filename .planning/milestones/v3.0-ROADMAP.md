## Milestone Summary

**Key Decisions:**

- AsyncThermometer separate from Thermometer because async methods break dyn compatibility
- Used embassy-time Timer for async delays (already in project)
- Separate LEDC timers: Timer0 for SSR, Timer1 for Fan (resolved PWM conflicts)
- StaticCell with raw pointer pattern for runtime-initialized statics

**Issues Resolved:**

- Fixed Use-After-Free bug in make_static
- Eliminated static_mut_refs warnings with StaticCell pattern
- Fixed OT2 parser returning wrong value
- Async temperature reading now wired into control loop
- Dead code removed, warnings reduced to ~4

**Issues Deferred:**

- Pre-existing critical-section build issue (not v3.0 related)
- Minor static mut workarounds remain (documented as safe)

**Technical Debt Incurred:**

- Static mut pointer workarounds remain (info-level, documented safe)
- Pre-existing build warnings in dependencies
