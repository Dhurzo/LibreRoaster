# Milestone v2.5: Artisan Edge Cases

**Status:** ✅ SHIPPED 2026-02-17
**Phases:** 44-45
**Total Plans:** 3

## Overview

This milestone focused on fixing Artisan protocol edge cases and locking them down with tests. The goal is exact READ framing and correct ROR state updates with regression coverage.

## Phases

### Phase 44: Protocol Framing Contract

**Goal**: READ responses use exact CSV framing with a single terminator
**Depends on**: None (v2.4 complete)
**Plans**: 2 plans

Plans:

- [x] 44-01: Sanitize and lock READ CSV formatting
- [x] 44-02: Centralize CRLF terminator at dual output boundary

**Details:**
Requirements Covered:
- PROT-01: READ response terminates with exactly one CRLF
- PROT-02: READ response is a 4-value CSV with one-decimal precision (ET,BT,HEATER,FAN)
- ARCH-01: A centralized terminator policy appends CRLF at a single output boundary

Success Criteria:
1. Artisan receives READ responses that end with a single CRLF and never a double terminator
2. READ responses contain exactly four CSV values in ET,BT,HEATER,FAN order with one-decimal precision
3. READ responses show identical terminator behavior regardless of output path (USB CDC or UART)

### Phase 45: ROR State + Regression Tests

**Goal**: ROR updates correctly and tests prevent framing regressions
**Depends on**: Phase 44
**Plans**: 1 plan

Plans:

- [x] 45-01: Fix ROR state updates and add regression tests

**Details:**
Requirements Covered:
- ROR-01: delta_bt updates last_bt so ROR becomes non-zero after the second BT sample
- TEST-01: Tests cover READ terminator and ROR update behavior

Success Criteria:
1. After the second BT sample, ROR becomes non-zero when BT changes during a roast session
2. Running the test suite validates READ terminator behavior and ROR update behavior for regressions

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**
- Decision: Centralize CRLF termination at the dual output boundary (Rationale: Prevent double terminators across USB CDC/UART)
- Decision: Reset formatter state on START/STOP transitions (Rationale: Avoid stale ROR state across sessions)

**Issues Resolved:**
- Double CRLF terminators in READ responses when both formatter and transport appended CRLF
- Invalid READ values (NaN/inf) leaking into CSV output
- ROR remaining zero due to last_bt not updating after initial samples

**Issues Deferred:**
- Integration tests still call format_read_response instead of the runtime format_read_response_full path

**Technical Debt Incurred:**
- Update integration tests to cover the runtime READ formatting path used by the control loop
