## Overview

v4.4 refactors duplicate SSR control code into shared base struct/trait and creates centralized test stubs to eliminate duplication. The milestone starts at Phase 75 and maps every v1 requirement to a delivery boundary.

## Phases

### Phase 75: SSR Refactoring

**Goal**: Extract common state into SsrControlBase and define SsrControlTrait to eliminate code duplication between SsrControl and SsrControlSimple.
**Depends on**: Nothing (first phase of v4.4)
**Plans**: 2 plans

Plans:

- [x] 75-01-PLAN.md — Extract SsrControlBase and traits, refactor both SSR types
- [x] 75-02-PLAN.md — Add missing trait implementations (gap closure)

**Details:**

Extracted common state from SsrControl and SsrControlSimple into a shared SsrControlBase struct with fields: hardware_status, current_duty, last_duty_delta_ticks, retry_count, last_detection_check, is_pwm_enabled. Defined three focused traits (HeatSourceDetector, PeriodicCheck, StatusGetters) with appropriate default implementations. Both SsrControl and SsrControlSimple now embed SsrControlBase and implement the StatusGetters trait, delegating common state access through the base struct. Eliminated ~90 lines of duplicated code while maintaining full backward compatibility for the public API.

**Key decisions:**
- Trait granularity: Used multiple smaller traits organized by capability rather than one monolithic trait
- Default implementations: Rich defaults in StatusGetters for SsrControlBase, explicit implementations for SsrControl
- API compatibility: Full backward compatibility maintained - public API unchanged
- Module location: SsrControlBase and traits in same module (not submodule)

### Phase 76: Test Infrastructure

**Goal**: Create shared test stubs module to eliminate ~5x duplication in test helpers across the codebase.
**Depends on**: Phase 75 (SSR refactoring must be complete first)
**Plans**: 1 plan

Plans:

- [x] 76-01-PLAN.md — Create tests/common/mod.rs with StubHeater, StubFan, StubThermometer, and helper functions

**Details:**

Created tests/common/mod.rs with shared stub implementations using RefCell for interior mutability. StubHeater implements Heater trait with call history (RefCell<Vec<HeaterCall>>), StubFan implements Fan trait with call history (RefCell<Vec<FanCall>>), and StubThermometer implements Thermometer trait with configurable temperature returns. Added reset_channels() and collect_output() helper functions for test isolation. Fixed Cargo.toml to move embassy-executor to main dependencies for host target compilation.

## Milestone Summary

**Key Decisions:**
- Decision: Trait delegation pattern (Rationale: Maintains consistency with existing code structure)
- Decision: RefCell for interior mutability in test stubs (Rationale: Per accumulated decisions from STATE.md)
