# Requirements: LibreRoaster v4.0 (Archived)

**Defined:** 2026-02-19
**Core Value:** Artisan can read temperatures and control heater/fan during a roast session via serial connection.

## v4.0 Requirements

Requirements for fixing the async sensor race condition and proving concurrency safety.

### Async Mutex Migration

- [x] **ASYNC-01**: Replace `ServiceContainer.roaster` field with `embassy_sync::Mutex<CriticalSectionRawMutex, RoasterControl>` — validated via the ServiceContainer migration (Phase 58 Plan 1) and successful builds.
- [x] **ASYNC-02**: Remove the take/replace pattern from `roaster_async_sensor_read()` — validated during the async lock migration (Phase 58 Plan 2).
- [x] **ASYNC-03**: Ensure `roaster_async_sensor_read()` uses `self.roaster.lock().await` — validated when all async callers switched to the new awaitable pattern.
- [x] **ASYNC-04**: Provide an async version of `with_roaster()` that awaits the EmbassyMutex — validated via the introduction of `with_roaster_async()` and task updates.
- [x] **ASYNC-05**: Update every caller of `with_roaster()` to the async API — validated by the updated task and USB CDC code pending only deprecation warnings.
- [x] **ASYNC-06**: Prove concurrent sensor reads do not race via a host integration test — validated by `tests/concurrent_sensor_test.rs` with the `async-lock-depth-metrics` instrumentation (Phase 60 Plan 1).

### Sync Access (Optional)

- [x] **SYNC-01**: Provide a critical-section-based sync access path for ISR contexts — validated via the preserved `roaster_sync` field and deprecated wrappers (Phase 58 Plans 1-4).

## v4.x Requirements

Command transport resilience requirements remain part of the broader roadmap.

### Command Transport Resilience

- [x] **COMMAND-01**: Concurrent USB CDC and UART0 bursts traverse `queue_processor_task` without drops — previously validated in Phase 59.
- [x] **COMMAND-02**: Queue processor instrumentation exposes `queue_depth/backlog_event` metrics consumable by host tests — previously validated in Phase 59.
- [x] **DOC-01**: README documents how to run and interpret the concurrency test and instrumentation metrics — previously validated in Phase 59.
