# Requirements: LibreRoaster v2.5

**Defined:** 2026-02-17
**Core Value:** Artisan can read temperatures and control heater/fan during a roast session via serial connection.

## v2.5 Requirements

### Protocol Framing

- [x] **PROT-01**: READ response terminates with exactly one CRLF — validated v2.5
- [x] **PROT-02**: READ response is a 4-value CSV with one-decimal precision (ET,BT,HEATER,FAN) — validated v2.5

### Formatter State

- [x] **ROR-01**: delta_bt updates last_bt so ROR becomes non-zero after the second BT sample — validated v2.5

### Output Architecture

- [x] **ARCH-01**: A centralized terminator policy appends CRLF at a single output boundary — validated v2.5

### Testing

- [x] **TEST-01**: Tests cover READ terminator and ROR update behavior — validated v2.5

## v2.6 Requirements (Future)

### Formatter State

- **ROR-02**: ROR resets cleanly on START/STOP and formatter reset

### Testing

- **TEST-02**: Dual output routing tests validate terminator behavior across USB CDC and UART
- **TEST-03**: Protocol fuzz tests for malformed command framing

## Out of Scope

| Feature | Reason |
|---------|--------|
| Embed CRLF in formatter output | Causes double CRLF when transport also appends terminator |
| Legacy 7-value READ format | Breaks current protocol contract and existing expectations |
| Add ROR/time fields to READ | Changes READ contract; keep derived metrics in stream output |
