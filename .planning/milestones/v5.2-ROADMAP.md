# Milestone v5.2: Architecture Hardening & Validation

**Status:** ✅ SHIPPED 2026-03-20
**Phases:** 95-103
**Total Plans:** 21

## Overview

v5.2 hardened the core firmware stack: we fixed the blocking build, wired every hardware/error pathway through a unified RoasterError → AppError taxonomy, documented and automated the traceability matrix, and proved the evidence chain for HIL validation + diagnostics automation.

## Objectives

1. **Critically unblock the build** so an embedded `.bin` image can be produced and flashed.
2. **Normalize the error architecture** across sensors, SSR/fan, wiring, and AppError so telemetry carries source metadata end-to-end.
3. **Instrument full TRACE flow** from queue → actuation → telemetry → guard for regression triage and diagnostics.
4. **Validate hardware automation** with manifest-aware HIL scenarios, reports, and replay artifacts.

## Requirements

- **BUILD-01**: Binary production and doc proof.
- **RUST-03**: Error taxonomy + boundary contracts.
- **SOLID-03**: Traceability matrix tooling for regression triage.
- **HW-03**: Artifact-backed HIL scenarios with golden outputs.
- **DIAG-01**: Diagnostics coverage for InitError flows.

## Milestone Summary

- **Key Decisions:**
  - Bound control/diagnostic errors via centralized `From` conversions so the control loop can `?` through hardware helper failures without losing metadata.
  - Bumped `TRACE_EVENT_MAX_LEN` to 192 and widened the artisan output channel so safe-shutdown guard events can carry `error_category`/`error_source` in every trace line.
  - Treated safe-shutdown guard metadata as canonical: `scripts/replay_safe_shutdown.py` now revalidates guard fields, and the diagnostics automation archives `replay-report.json` alongside zip artifacts.
- **Issues Resolved:**
  - Removed duplicate embassy-time stubs so `cargo build --release --target riscv32imc-unknown-none-elf --features embedded` produces `libreroaster.bin`.
  - Normalized hardware errors through `RoasterError`/`AppError`, added mocks, and verified guard telemetry across the control loop.
  - Instrumented full TRACE flow, shipped parser/scripts, and documented how to rerun the regression matrix with real logs.
  - Delivered manifest-aware HIL validation runs plus analysis/playbook so HW-03 now has golden outputs.
  - Published `95-VERIFICATION`, `96-VERIFICATION`, `97-VERIFICATION`, `98-hil-validation-infrastructure-VERIFICATION`, and `103` artifacts for auditors.
- **Issues Deferred:**
  - Phase 104 (Safe-Shutdown Artifact Replay Automation) remains planned; the CLI + docs described in 104-01 are ready for the next milestone so automation can verify guard metadata repeatedly.
- **Technical Debt:**
